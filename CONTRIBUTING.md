# Contributing

See [Local Development](docs/development.md) for environment setup, tests,
small bug reproductions, and generated launcher archives.

Maintainers preparing a package or launcher release must follow the
[Release Checklist](docs/release.md). That guide covers version tags, updater
compatibility, release notes, artifacts, and post-publication verification.

Coding agents must also follow [AGENTS.md](AGENTS.md).
